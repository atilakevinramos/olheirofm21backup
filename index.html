Como utilizar o Moneyball Analyzer?

Siga o passo a passo para exportar seus jogadores do Football Manager 2021 e analisar os dados no nosso site.

01
Baixe a visualização personalizada

Primeiro, baixe o arquivo de visualização do Football Manager. Ele organiza as colunas da lista de jogadores com as informações necessárias para o funcionamento do analisador.

Baixar arquivo de visualização (.fmf)

O arquivo possui a extensão .fmf.

02
Instale o arquivo no Football Manager 2021

Após baixar o arquivo, coloque-o na pasta views do Football Manager 2021.

Documentos → Sports Interactive → Football Manager 2021 → views

No Windows, o caminho normalmente será:

Documentos\Sports Interactive\Football Manager 2021\views
Dica: se a pasta views não existir, crie uma pasta com esse nome dentro da pasta Football Manager 2021.

Não coloque o arquivo .fmf dentro da pasta de instalação do jogo. Ele deve ficar na pasta views dos seus documentos.

03
Abra o jogo e pesquise os jogadores

Agora abra o Football Manager 2021 e entre na área de pesquisa de jogadores.

Utilize os filtros do próprio jogo para encontrar os atletas que deseja analisar. Você pode pesquisar por idade, posição, nacionalidade, clube e outros critérios disponíveis no FM21.

Você pode fazer diferentes pesquisas. O analisador trabalhará com os jogadores que você exportar.
04
Carregue a visualização personalizada

Na lista de jogadores, abra o menu de visualizações (normalmente localizado na parte superior da tabela).

Procure a visualização personalizada que você colocou na pasta views e selecione-a.

Confira se as colunas foram carregadas corretamente antes de exportar os jogadores.
05
Selecione e exporte os jogadores em HTML

Com a lista de jogadores aberta e a visualização personalizada selecionada, faça o seguinte:

CTRL + A Seleciona todos os jogadores da lista.
CTRL + P Abre a opção de impressão/exportação.
  1. Selecione todos os jogadores com Ctrl + A.
  2. Pressione Ctrl + P.
  3. Escolha a opção de salvar em formato HTML.
  4. Salve o arquivo no seu computador.
Importante: salve o arquivo como HTML, e não como PDF. O analisador precisa ler a tabela de jogadores e suas estatísticas.
06
Envie o HTML para o Moneyball Analyzer

Agora falta pouco! Volte para a aba Analisador, selecione o arquivo HTML que você acabou de salvar e aguarde o processamento.

O site vai extrair os dados, calcular o Score Moneyball e apresentar a classificação dos jogadores.

O arquivo .fmf organiza as colunas dentro do jogo. O arquivo HTML contém os jogadores e estatísticas que serão enviados ao analisador.
